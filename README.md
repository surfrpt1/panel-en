# English i18n layer for the edgetunnel admin panel

Self-hosted English translations of the edgetunnel admin + login pages.

- `login/index.html` — login page
- `i18n-en.js` — runtime translation layer (DOM text nodes, `placeholder`/`title`/`aria-label`, `alert`/`confirm`, MutationObserver)
- `dict.json` — full key/value dictionary

Served via GitHub Pages at `https://surfrpt1.github.io/panel-en/`.
