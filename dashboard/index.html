🤔 Why ProxyIP / Reverse Proxy mode?

Reverse-proxy mode routes your traffic through a ProxyIP so that the Cloudflare connection stays stable and reachable in regions where the raw domain/IP is blocked. A ProxyIP is a server that forwards your vless/trojan traffic onward, hiding the real destination while the client still connects to Cloudflare.

Important: For the proxy to work you need a ProxyIP that also supports your protocol (vless/trojan over the same transport). Use Verify to test an address before saving, or use the Find more lists.

🔐 What is ECH?

Background

Encrypted Client Hello (ECH) encrypts the SNI (server name) inside the TLS handshake, so a middlebox cannot see which domain you are connecting to.

What problems does it solve?

Plaintext SNI lets network middleboxes (e.g. GFW) fingerprint and throttle Cloudflare traffic. ECH hides the SNI so the connection looks like a normal HTTPS request to any host.

How to use ECH

Enable ECH, pick a DNS server and SNI. Clients that support ECH: recent Xray/V2Ray, sing-box, and clients with ECH support enabled. For best compatibility use the default cloudflare-ech.com SNI.
